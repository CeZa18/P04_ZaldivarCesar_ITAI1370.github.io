Rock-Paper-Scissors-Lizard-Spock

Rock-Paper-Scissors-Lizard-Spock is a variant of the classic Rock-Paper-Scissors game, adding two more elements: Lizard and Spock. Each element has specific rules for winning against others.

This game is a fun way to explore decision-making and probability, and it can be used to demonstrate concepts in artificial intelligence, such as strategy and prediction. But mostly I coded this to learn programming. I started with Python, but I wanted to learn JavaScript and HTML/CSS, so I decided to code this game in JavaScript. The game is played against the computer, which makes random choices. The player selects their choice, and the game determines the winner based on the rules of Rock-Paper-Scissors-Lizard-Spock.

How to Play

  1. Both players choose their moves simultaneously.
  2. The game determines the winner based on the rules of Rock-Paper-Scissors-Lizard-Spock.
  3. Players can choose from the following options: Rock, Paper, Scissors, Lizard, or Spock.
  4. The player with the winning move gets a point.
